# Lâmina Paciente Modelo

Página estática da campanha **Paciente Modelo | Dr. Ritchie**, pronta para deploy na Vercel.

## Deploy na Vercel

1. Importe o repositório `gestaodeprojetosmax-bit/lamina-paciente-modelo-site` na Vercel.
2. Use o preset **Other**.
3. Deixe o Build Command vazio.
4. Deixe o Output Directory vazio ou use `.`.
5. Clique em **Deploy**.

A página não exige variáveis de ambiente. Os botões já apontam para o WhatsApp comercial configurado no HTML original.
